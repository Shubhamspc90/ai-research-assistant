# AI Research Assistant

An AI-powered research assistant built using LangChain, FastAPI, React, and Ollama Cloud.

## Project Overview

The AI Research Assistant allows users to interact with an AI agent through a web interface.

The system can use external tools such as web search and other utilities to retrieve information and provide useful responses.

## Planned Technology Stack

- Frontend: React + Vite
- Backend: FastAPI
- AI Framework: LangChain
- LLM: Ollama Cloud
- Database: PostgreSQL
- Version Control: Git + GitHub
